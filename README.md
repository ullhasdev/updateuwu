# updateuwu
an updater tool for lazy arch linux users 

## what it does
it updates AUR and pacman repos and also cleans cache files if you want to
<img width="1377" height="901" alt="image" src="https://github.com/user-attachments/assets/c087a09c-adae-4352-83c1-983e1a472494" />


## installation: 
 Open your terminal and create the script directly inside /usr/local/bin so you can run updateuwu from anywhere:
 sudo nano /usr/local/bin/updateuwu
 
## Grant execution permissions to the script:
sudo chmod +x /usr/local/bin/updateuwu

 ## run it 
 updateuwu

## customizing the name 
if you have already have a file named "updateuwu", go to
nano /usr/local/bin/updateuwu 
and change your name from arch-sama to whatever you want
